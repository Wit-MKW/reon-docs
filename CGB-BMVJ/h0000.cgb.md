# `h0*.cgb`
_Including `h0000.cgb`, the first file downloaded by the game._

This file simply contains a list of menu options. Each one may link to another
`h0*.cgb` file, an `h8*.cgb` file, or `RomList.cgb`.

## File format

The first four bytes of the file must be `MNGL` in ASCII (`4D 4E 47 4C`). The
next byte indicates the number of menu options, and is followed by five bytes
for each menu option (of which the last should always be null). If the first of
an option's five bytes is `0` or `8` in ASCII (`30` or `38` respectively), the
string is inserted into the filename `h*.cgb` and the option in question links
to that file; otherwise, it links to `RomList.cgb`.

After each option's five bytes come the null-terminated names of the options,
in the game's proprietary encoding.
