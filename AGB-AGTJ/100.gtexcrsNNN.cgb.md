# `100.gtexcrsNNN.cgb`
_Where `NNN` is an integer `000`-`255`._

This file holds the data for custom track number `NNN`. The track number
downloaded by the game is decided entirely by `gtconfig.cgb`.

## File format
| Offset(s)   | Description                             |
|-------------|-----------------------------------------|
| 0x000       | Track number (`NNN`).                   |
| 0x001       | Billboard type (0=normal, 1=Famitsu).   |
| 0x002-0x003 | Zero (0).                               |
| 0x004-0x019 | Track title.                            |
| 0x01A-0x01B | Track length in metres.                 |
| 0x01C-0x043 | Tile row #1.                            |
| 0x044-0x06B | Tile row #2.                            |
| 0x06C-0x093 | Tile row #3.                            |
| 0x094-0x0BB | Tile row #4.                            |
| 0x0BC-0x0E3 | Tile row #5.                            |
| 0x0E4-0x10B | Tile row #6.                            |
| 0x10C-0x10F | Little-endian sum of bytes 0x000-0x10B. |

## Tile format
Tiles are laid out in six rows of ten tiles each, going from west to east and
from north to south. Each tile takes four bytes in the following format:

| Offset | Description                                           |
|--------|-------------------------------------------------------|
| 0x0    | Road type (0=empty tile).                             |
| 0x1    | Rotation (0=none, 1=right, 2=180, 3=left).            |
| 0x2    | Quadrant (0=empty, 1=single, 2=NW, 3=NE, 4=SW, 5=SE). |
| 0x3    | Zero (0).                                             |

## Notes
- Due to an integer overflow bug, tracks longer than 8192 metres are unplayable.
  (This mostly amounts to trivia, as it is somewhat difficult to make such a
  long track, and the end result is not very fun to play.)
- For large tiles, the quadrant number is chosen _after_ the rotation (e.g.
  quadrant 2 is always west of quadrant 3).
