# Doraemon: Midori no Wakusei Doki-Doki Daikyuushuutsu!
_Roughly "Doraemon: The Heart-Pounding Green Planet Rescue!"_

This game released only in Japan, on 2001-04-27. It is an action-adventure game
in which the player characters use the titular character's gadgets in order to
help them save the planet. It has only one mobile feature, which is accessed
through one such gadget, namely the Time Phone. It allows the player to receive
advice, extra items, and even skip parts of levels.
