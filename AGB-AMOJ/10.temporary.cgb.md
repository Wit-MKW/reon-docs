# `10.temporary.cgb`
After uploading the player's score, the game downloads this file in order to
check the player's rank (if they have one). A rank of 10th or better is
displayed as such, while a rank worse than 10th is displayed as "unranked".

## Query format
| Offsets   | Description           |
|-----------|-----------------------|
| 0x00-0x07 | ASCII: "`myscore=`".  |
| 0x08-0x17 | ASCII hex: `myscore`. |

## File format
| Offsets | Description             |
|---------|-------------------------|
| 0x0-0x1 | Zero if no rank.        |
| 0x2-0x5 | Big-endian rank number. |

## Notes
- If there is no rank number (that is, if offsets 0x0-0x1 are zero), space does
  not need to be reserved for it; in other words, the file may be cut off after
  offset 0x1.
- Because this is an authenticated file, the game requires three separate HTTP
  requests in order to download it. While the query is not sent to the server
  until the final request (which is, in fact, the only `POST` request), the
  first request contains a `Content-Length: 24` HTTP header, which may cause
  issues with some HTTP server implementations.
