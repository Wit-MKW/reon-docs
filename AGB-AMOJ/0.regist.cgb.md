# `0.regist.cgb`
This is the file in which the game uploads the player's score. It is uploaded
twice: once with the two `today` fields set to zero, and again with them both
corresponding to the current month.

## File format
| Offset(s) | Description                         |
|-----------|-------------------------------------|
| 0x00-0x27 | `myname`.                           |
| 0x28-0x2F | `myscore`.                          |
| 0x30      | Player's gender (0=male, 1=female). |
| 0x31      | Player's age in years.              |
| 0x32      | Player's home prefecture.           |
| 0x33      | `today`.                            |
