# `0.dlghost3.cgb`
This file is queried in order to download a ghost by its Kart ID. This includes
downloading ghosts by their prefecture and driver rank numbers, since the server
does not directly provide ghost data for such searches.

## Query format
| Offsets   | Description                     |
|-----------|---------------------------------|
| 0x00-0x04 | ASCII: "`myid=`".               |
| 0x05-0x24 | ASCII hex: Kart ID.             |
| 0x25-0x37 | ASCII: "`&state=00&driver=00`". |

## File format
As `0.dlghost.cgb`.
