# `0.dlghostdr.cgb`
This file is queried in order to obtain a player's Kart ID by their driver and
their rank number among other users of that driver.

## Query format
| Offsets   | Description                   |
|-----------|-------------------------------|
| 0x00-0x09 | ASCII: "`ghostrank=`".        |
| 0x0A-0x11 | ASCII hex: driver rank no.    |
| 0x12-0x22 | ASCII: "`&state=00&driver=`". |
| 0x23-0x24 | ASCII hex: driver ID.         |

## File format
As `0.dlghostid.cgb`.
