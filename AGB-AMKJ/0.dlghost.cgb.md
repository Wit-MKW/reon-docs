# `0.dlghost.cgb`
This file is queried in order to download a ghost by its global rank number.

## Query format
| Offsets   | Description                     |
|-----------|---------------------------------|
| 0x00-0x09 | ASCII: "`ghostrank=`".          |
| 0x0A-0x11 | ASCII hex: global rank no.      |
| 0x12-0x24 | ASCII: "`&state=00&driver=00`". |

## File format
| Offset(s)     | Description                               |
|---------------|-------------------------------------------|
| 0x0000-0x0005 | Timestamp.                                |
| 0x0006-0x0009 | Big-endian global rank count.             |
| 0x000A-0x000B | Zero means no ghost data here.            |
| 0x000C        | Driver ID.                                |
| 0x000D-0x0011 | Nickname.                                 |
| 0x0012-0x0013 | Big-endian time in units of 1/100 second. |
| 0x0014-0x1013 | Save file sector for ghost.               |
| 0x1014-0x1023 | Kart ID.                                  |
| 0x1024-0x1027 | Big-endian global rank count.             |
| 0x1028-0x102B | Unused.                                   |
| 0x102C-0x103F | Big-endian prefecture rank count.         |
| 0x1040-0x1043 | Big-endian driver rank count.             |

## Notes
- The timestamp is not used by the game.
- If there is no ghost data, the file may be cut off after offset 0x000B.
- The save file sector is as uploaded; the game overwrites parts of it as
  necessary.
- The prefecture and driver rank counts pertain to the player downloading the
  ghost, not the ghost itself.
