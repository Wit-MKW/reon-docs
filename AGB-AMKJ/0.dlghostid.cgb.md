# `0.dlghostid.cgb`
This file could be queried to obtain a player's Kart ID by their global rank
number, but the game only ever uses `0.dlghost.cgb` for this purpose.

## Query format
| Offsets   | Description                     |
|-----------|---------------------------------|
| 0x00-0x09 | ASCII: "`ghostrank=`".          |
| 0x0A-0x11 | ASCII hex: global rank no.      |
| 0x12-0x24 | ASCII: "`&state=00&driver=00`". |

## File format
| Offsets   | Description                   |
|-----------|-------------------------------|
| 0x00-0x05 | Timestamp.                    |
| 0x06-0x09 | Big-endian global rank count. |
| 0x0A-0x0B | Zero means no Kart ID here.   |
| 0x0C-0x1B | Kart ID.                      |

## Notes
- The timestamp is not used by the game.
- If there is no Kart ID, the file may be cut off after offset 0x0B.
