# `0.dlghostst.cgb`
This file is queried to obtain a player's Kart ID by their prefecture and their
rank number within that prefecture.

## Query format
| Offsets   | Description                    |
|-----------|--------------------------------|
| 0x00-0x09 | ASCII: "`ghostrank=`".         |
| 0x0A-0x11 | ASCII hex: prefecture rank no. |
| 0x12-0x18 | ASCII: "`&state=`".            |
| 0x19-0x1A | ASCII hex: prefecture ID.      |
| 0x1C-0x24 | ASCII: "`&driver=00`".         |

## File format
As `0.dlghostid.cgb`.
