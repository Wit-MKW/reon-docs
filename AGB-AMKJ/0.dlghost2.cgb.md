# `0.dlghost2.cgb`
This file is queried in order to download a ghost by its time.

## Query format
| Offsets   | Description                                             |
|-----------|---------------------------------------------------------|
| 0x00-0x0A | ASCII: "`ghostscore=`".                                 |
| 0x0B-0x0E | ASCII hex: race time in units of 1/100 second plus one. |
| 0x0F-0x21 | ASCII: "`&state=00&driver=00`".                         |

## File format
As `0.dlghost.cgb`.
