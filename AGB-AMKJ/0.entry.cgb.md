# `0.entry.cgb`
This file is uploaded with ghost data for the rankings.

## File format
| Offset(s)     | Description                               |
|---------------|-------------------------------------------|
| 0x0000-0x000F | Kart ID.                                  |
| 0x0010        | Track no.                                 |
| 0x0011        | Driver ID.                                |
| 0x0012-0x0016 | Nickname.                                 |
| 0x0017        | Prefecture ID.                            |
| 0x0018        | Check byte A.                             |
| 0x0019        | Check byte B.                             |
| 0x001A-0x001B | Big-endian time in units of 1/100 second. |
| 0x001C-0x101B | Save file sector for ghost.               |
| 0x101C-0x102B | Full name.                                |
| 0x102C-0x1037 | Phone number.                             |
| 0x1038-0x103F | Postal code.                              |
| 0x1040-0x10BF | Home address.                             |

## Notes
- Outside of Mobile GP, the full name and home address are filled with
  capitals _J_ (`2A`), while the two numbers are filled with slashes (`0F`).
- In an unmodified game, the postal code is always seven digits followed
  by a lowercase _p_ (`50`).
